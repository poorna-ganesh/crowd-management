# CrowdManage — Smart Crowd Management Application

## Overview
CrowdManage is a prototype web application designed to manage large crowds in pilgrimage and temple areas.  
It provides AI/ML-based crowd prediction, smart queue management, real-time heatmaps, emergency alerts, and traffic/parking assistance — all integrated with Google Maps.

---

## Features
- **AI/ML-based Crowd Prediction**: Forecast visitor surges using historical patterns (mock model included).
- **Smart Queue & Ticketing**: Join a virtual queue, view token number, and reduce physical crowding.
- **Crowd Heatmap**: Live visualization of crowd density using Google Maps API.
- **Emergency Alerts**: Trigger panic/emergency alerts for first responders.
- **Traffic & Parking (Stub)**: Placeholder for intelligent parking and shuttle coordination.
- **Multilingual Support**: Switch between English, Hindi, Gujarati (more can be added).
- **Accessibility**: High-contrast mode and adjustable text size for elderly/differently-abled users.

---

## Tech Stack
- **Frontend**: HTML, CSS, Vanilla JavaScript (Google Maps JS API)
- **Backend**: Python Flask
- **Data/ML**: Pandas, Scikit-learn (stub for now, extendable with real data)
